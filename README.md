# Government Builder Prototype

This subsystem is a standalone design tool for experimenting with flexible government types, voting systems, permission models, and territory structures.

## Goal

Create a small, interactive builder that can support a wide range of political structures without hardcoding a single governance model.

## Supported patterns

- Dictatorship
- Democracy
- Anarchy
- Commune / syndical structure
- Constitutional or hybrid government

## Core building blocks

- Leadership model
- Voting model
- Membership rules
- Permission map
- Territory control rules
- Enforcement logic

## Current prototype behavior

- Select a government archetype and customize it.
- Add policy clauses and permission rules.
- Simulate a political report and see the resulting power structure.
- Use this as a design sandbox before wiring it into the main game loop.
